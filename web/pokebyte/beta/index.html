Early hardware test

Experimental USB installation for the Waveshare ESP32-S3-Touch-AMOLED-1.75

Experimental — not the finished PokéByte release

You may lose the TamaPoke firmware and Pokémon save on internal flash. You have chosen to skip the backup. Do not use this on a device whose existing data you want to keep.

The microSD will not be intentionally formatted, erased or uploaded to by this beta installer. Your existing Pokémon sprites remain on the card. Firmware will fall back to original scenery if the 12 approved backgrounds are not yet on microSD. No separate software download or SD reader is needed to attempt the firmware test.

Wrong board = risk. Only the round Waveshare ESP32-S3-Touch-AMOLED-1.75 (466×466, 16 MB flash, 8 MB PSRAM). The browser detects the ESP32-S3 chip, not the exact screen/controller model.

Before testing

  1. Leave your microSD with original Pokémon sprite files inserted.
  2. Connect the Waveshare to the PC with a USB-C data cable.
  3. Open this HTTPS page in desktop Chrome or Edge.
  4. Check the option below and click Test-install PokéByte; approve your browser's USB port prompt.
  5. If ESP Web Tools asks about erasing memory, choose not to erase all flash. The manifest writes only bootloader, partition metadata, OTA boot selection, and firmware; it does not target the internal NVS save sector or the SD card.

Limitations: background BMPs are not uploaded by this first experimental installer. The first test is to check the boot, display, touch, care, existing sprite loading, and native temperament/ambience. If the device doesn't start correctly, disconnect it and report what you see; the program stays in source control for debugging.

This browser does not support Web Serial. Use desktop Chrome or Edge. Open this page over HTTPS in Chrome or Edge.
