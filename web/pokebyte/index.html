How installation will work

Once the approved firmware is ready, this page will guide you through a safe release process. Nothing below initiates a connection or changes files today.

01

Check your Waveshare model

Use the ESP32-S3-Touch-AMOLED-1.75, with the round 466 × 466 display. The 1.75C is a different board and will not be accepted by this release.

02

Protect your Pokémon

Back up the complete flash image, saved Pokémon/NVS, and current microSD first. The installer will stay locked until our backup and recovery instructions have been verified.

03

Install verified firmware

A future ESP Web Tools installer will guide a USB connection in a supported desktop browser. There is no firmware manifest or flashable PokéByte image here yet.

04

Load approved game assets

Install the exact 12 approved backgrounds and 303 original Pokémon BIN files using a verified, non-destructive microSD procedure. Your saved Pokémon and existing card contents matter.
