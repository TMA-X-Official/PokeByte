One-click installation, no manual downloads

For the finished release, you'll only need a compatible Waveshare board, a USB-C data cable and desktop Chrome or Edge. The browser handles the firmware and game assets; you don't download or install any separate software. The browser's device-permission prompt is still required.

01

Connect with USB-C

Use the round ESP32-S3-Touch-AMOLED-1.75 (466 × 466). Open this page in desktop Chrome or Edge and connect a data-capable cable. The 1.75C is not supported.

02

Click Install

Choose the USB device when the browser asks. The finished installer will check compatibility, protect existing saved Pokémon through a verified backup/update path and refuse unsafe devices. No command line or separate installer.

03

Automatic firmware setup

The page will fetch verified PokéByte firmware directly from the hosted release and write it over USB. You will not need to download a .bin, install Python or use Arduino IDE. The install will not silently erase NVS or format the SD card.

04

Assets automatically verified

The page will check and, when needed, transfer the 12 approved backgrounds and 303 original Pokémon BIN files to the existing microSD over USB, without a card reader. Already-verified files should be skipped; unique card contents must be preserved.

For existing TamaPoke owners

Your original Pokémon and microSD contents matter. A future installer must preserve the existing save and avoid erasing or formatting storage. The original TamaPoke USB sprite uploader can send files but cannot back up a full microSD. We will not enable an upgrade until an appropriate safe migration and recovery procedure is verified on physical hardware.
